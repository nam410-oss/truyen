Đăng chương mới

Chưa kết nối được server đăng chương. Trang này cần chạy qua server cục bộ:
  1. Mở PowerShell tại thư mục dự án (d:\truyen).
  2. Chạy: powershell -ExecutionPolicy Bypass -File scripts\server.ps1
  3. Mở http://localhost:8080/dang-chuong.html
